# Filosofía de FORJA

FORJA NO es una aplicación para registrar hábitos. FORJA es un sistema diseñado para construir disciplina de forma sostenible. El objetivo no es que el usuario complete formularios — es que invierta el menor tiempo posible registrando información y el mayor tiempo posible viviendo su día. Estos principios guían absolutamente todas las decisiones del proyecto y aplican a cada Sprint.

**Principio 1 — Registrar debe ser más rápido que recordar.** Si una acción tarda demasiado, debe rediseñarse.

**Principio 2 — Cada dato debe tener un propósito.** No se recolecta información "por si acaso". Cada dato registrado debe transformarse después en información útil.

**Principio 3 — Los datos generan conocimiento.** El conocimiento genera decisiones. Las decisiones generan acciones. Las acciones generan resultados. Los resultados generan motivación.

**Principio 4 — Cada acción completada debe producir una sensación inmediata de progreso.** No se busca generar adicción; se busca reforzar hábitos saludables mediante una experiencia satisfactoria, clara y motivadora. El usuario debe sentir que está construyendo algo valioso cada vez que completa una acción.

**Principio 5 — Eliminar toda fricción innecesaria.** Menos clics. Menos pantallas. Menos texto. Menos configuración. Más automatización. Más inteligencia. Más velocidad.

**Principio 6 — La interfaz nunca debe sentirse como una planilla.** Debe sentirse como una herramienta de evolución personal. Cada pantalla debe transmitir claridad, orden, enfoque, progreso y disciplina.

**Principio 7 — Automatizar siempre que sea posible.** El sistema debe recordar; el usuario no. Reutilizar favoritos, comidas frecuentes, plantillas, historial, IA, sugerencias y autocompletado. El usuario nunca debería escribir dos veces la misma información.

**Principio 8 — Toda funcionalidad nueva debe responder antes de implementarse:** ¿Reduce el tiempo del usuario? ¿Reduce la carga mental? ¿Genera información útil? ¿Ayuda a cumplir el hábito? ¿Hace sentir progreso? Si la respuesta es NO en la mayoría, esa funcionalidad probablemente no pertenece a FORJA.

**Objetivo final:** Registro → Datos → Información → Acción → Progreso → Motivación → Constancia. Ante un conflicto entre una implementación propuesta y esta filosofía, priorizar siempre simplicidad, velocidad y experiencia del usuario.
